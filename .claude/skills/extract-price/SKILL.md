# extract-price

Получает один URL страницы товара и возвращает структурированные данные о цене.

## Вход

Один URL страницы товара, например `https://example-shop.ru/product/12345`.

Если URL не передан или передано несколько — попроси пользователя указать ровно одну ссылку.

## Выход

Ровно один JSON-объект, без пояснений вокруг:

```json
{
  "regular_price": 12990,
  "sale_price": 9990,
  "has_credit": true
}
```

| Поле | Тип | Значение |
|---|---|---|
| `regular_price` | число | Обычная цена (без скидки). |
| `sale_price` | число или `null` | Цена со скидкой. `null`, если скидки нет. |
| `has_credit` | boolean | `true`, если на странице доступна рассрочка или оплата частями. |

Цены — числа в валюте страницы, без пробелов, символов валюты и разделителей тысяч (`12 990 ₽` → `12990`, `1 299,50 ₽` → `1299.5`).

## Алгоритм

1. **Загрузи страницу** через WebFetch. Если WebFetch не справился (ошибка, пустой ответ, страница рендерится JS), попробуй `curl -sL -A "Mozilla/5.0" "<URL>"`.
2. **Найди цены**, проверяя источники по порядку надёжности:
   1. JSON-LD (`<script type="application/ld+json">`) — объект `Product` → `offers` (`price`, `highPrice`, `lowPrice`, `priceSpecification`).
   2. Микроразметка и мета-теги: `itemprop="price"`, `product:price:amount`, `og:price:amount`.
   3. Видимый текст карточки товара: перечёркнутая цена (`<del>`, `<s>`, классы вида `old-price`, `price-old`, `crossed`) — обычная; выделенная текущая цена — цена со скидкой.
3. **Определи `regular_price` и `sale_price`**:
   - Две цены (старая и новая) → `regular_price` = бо́льшая, `sale_price` = меньшая.
   - Одна цена → `regular_price` = она, `sale_price` = `null`.
   - Не учитывай цены по карте лояльности, за подписку, «от N ₽» в похожих товарах, цены доставки и аксессуаров.
4. **Определи `has_credit`**: `true`, если в карточке товара есть признаки рассрочки или оплаты частями — «рассрочка», «в кредит», «Сплит», «Долями», «Плайт», «оплата частями», «N ₽/мес», «× N платежей», «installment». Иначе `false`.
5. **Верни JSON** в формате из раздела «Выход».

## Ошибки

Если цену определить не удалось (страница недоступна, товара нет в наличии без цены, капча), верни все поля `null`:

```json
{
  "regular_price": null,
  "sale_price": null,
  "has_credit": null
}
```

Не выдумывай цены: если значение не найдено на странице, ставь `null`.
